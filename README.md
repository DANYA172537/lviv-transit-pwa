# Львів Транспорт

Легкий PWA-планувальник громадського транспорту Львова. Він працює як звичайний сайт у Safari, а також можна додати на головний екран iPhone.

## Що вже є

- пошук маршруту за GTFS-розкладом;
- порівняння часу очікування, пересадок, тривалості та піших переходів;
- пошук зупинок і популярних місць;
- live GPS транспорту через GTFS Realtime;
- карта Leaflet + список активних автобусів/тролейбусів;
- вибір початку й пункту призначення кліком по карті;
- зворотне геокодування назви обраної точки через Nominatim/OpenStreetMap;
- offline shell для PWA;
- жодного ключа OpenAI та жодного ШІ в критичному розрахунку.

## Запуск

Потрібен Node.js 20 або новіший.

```bash
npm install
npm start
```

Відкрий `http://localhost:4173`.

Якщо порт 4173 зайнятий:

```bash
PORT=4174 npm start
```

На Windows PowerShell:

```powershell
$env:PORT=4174; npm start
```

## Автоматичне оновлення

PWA перевіряє новий `service worker` і версії файлів:

- при відкритті;
- коли вкладка знову стає активною;
- після появи мережі (`online`);
- кожні 15 хвилин, поки застосунок відкритий.

Якщо сервер має нову версію, вона завантажується у фоні, активується автоматично і сторінка перезавантажується. Користувачу не потрібно щоразу знову «качати» застосунок.

Важливе обмеження iOS: коли PWA повністю закритий, браузер не гарантує запуск фонового JavaScript. Тому найнадійніше оновлення відбувається під час наступного відкриття або коли додаток знову отримує мережу. Для цього сценарію потрібен HTTPS і встановлення через Safari.

## Як вибрати місце на карті

1. Відкрий блок **Де зараз транспорт**.
2. Натисни **Звідки** або **Куди**.
3. Клацни потрібну точку на карті.
4. Натисни **Маршрут →** на карті або **Знайти маршрут** у формі вгорі.

На карті буде позначено `З` для початку та `К` для призначення. У полях показується українська назва вулиці/місця, а координати залишаються внутрішніми. Якщо Nominatim недоступний, програма все одно використає координати й найближчі зупинки.

## Як відкрити на iPhone

1. Задеплой сервер на HTTPS-хостинг, який підтримує Node.js.
2. Відкрий посилання в Safari.
3. Натисни **Поділитися**.
4. Вибери **На екран Home**.

Для повної роботи PWA, геолокації та service worker потрібен HTTPS. Apple не дозволяє встановлювати звичайний iOS-додаток без App Store, але Safari/PWA дає майже такий самий сценарій: окремий значок, повноекранний режим і збережені налаштування.

У репозиторії вже є `Dockerfile`, `render.yaml` та покрокова інструкція [`DEPLOY.md`](DEPLOY.md), тому проєкт можна задеплоїти на Node-хостинг без окремого фронтенд-збірника.

## Джерела даних

Сервер завантажує відкриті дані Львівської міської ради / ЛьвівАвтодор:

- `https://track.ua-gis.com/gtfs/lviv/static.zip`
- `https://track.ua-gis.com/gtfs/lviv/vehicle_position`
- `https://track.ua-gis.com/gtfs/lviv/trip_updates`

Ліцензія транспортних даних: CC BY 4.0. Посилання на джерело є в інтерфейсі та в `server.js`. Для назв точок і карти використовується OpenStreetMap / Nominatim.

## Важливі обмеження MVP

- GPS показується тільки для транспорту, який перевізник віддає у live- feed.
- Розклад може змінюватися; сервер кешує офіційний ZIP на 6 годин.
- Піші переходи рахуються приблизно за координатами, без пішої навігації по тротуарах.
- Початковий алгоритм шукає до трьох поїздок; для дуже складних поїздок може знайти менше варіантів, ніж Google Maps.
- Це не сервіс квитків і не гарантія, що автобус приїде вчасно.

## Наступні кроки

- додати кеш маршрутів у браузері;
- додати точніші live-прибуття на конкретній зупинці;
- додати улюблені місця;
- додати push-сповіщення про затримки (через HTTPS і дозвіл користувача);
- перенести розкладний пошук на RAPTOR/OTP, якщо знадобиться масовий production-варіант.
